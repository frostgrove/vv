`en/` is the source. A page in `ru/` is a translation of the file of the same
name beside it, so the two directories hold the same filenames and the same
headings — change one and the other is stale.

Code, identifiers, `db` tags, JSON keys and the `[[D-NNN]]` / `[[UC-NNN]]` /
`[[FL-NNN]]` references are the same in both. Only the prose differs.
