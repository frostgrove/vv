# catalog — схема, прочитанная один раз

```go
import "github.com/frostgrove/vv/crud/catalog"
```

**Модуль:** корневой · **Зависит от:** `crud` и стандартной библиотеки

Схема одной базы данных, прочитанная при старте приложения и отвечающая из
памяти. Четыре диалекта, и все через `crud.Source.Query` — тот же интерфейс из
двух методов, что используют все остальные.

**Он нужен вам**, когда вы хотите, чтобы нарушение называло колонки, которые
не назвал драйвер (составной unique в PostgreSQL, что угодно в SQLite), или
когда вы используете [probe](probe.md), который без него работать не может.

---

## Загрузка

```go
cat, err := catalog.Load(ctx, crudsql.Postgres(sqlDB))
if err != nil {
    log.Fatalf("reading the schema: %v", err)   // падать здесь, а не при первой коллизии
}
```

Всё после этого вызова — память. `Table` и `Constraint` не принимают контекст
и не делают I/O — сигнатура, принимающая контекст, была бы ленивым загрузчиком,
а **ленивый загрузчик не может упасть при старте приложения** ([[D-041]]).

Отказ есть отказ: `Load` возвращает либо nil `Catalog`, либо готовый — никогда
наполовину собранный рядом с nil-ошибкой. Тихая деградация до пустой схемы
означала бы, что читающая её функциональность отключена в продакшене, а
единственный симптом — то, что она никогда ничего не сообщает.

`Load` не принимает **ни опций, ни таймаута**. Он выполняется один раз при
объявлении, на контексте, которым владеет приложение, а таймаут по умолчанию
здесь превратил бы медленный, но здоровый старт в фатальный отказ.

## Поиск

```go
type Catalog interface {
    Table(name string) (*Table, bool)
    Constraint(table, name string) (*Constraint, bool)
    Dialect() string     // "postgres", "mysql", "mariadb", "sqlite"
}
```

`Constraint` принимает таблицу **вместе с** именем, потому что в MySQL имя
индекса уникально в пределах таблицы, а не в пределах схемы — первичный индекс
любой таблицы InnoDB называется `PRIMARY`, а MariaDB сообщает о дублирующемся
ключе как `for key 'PRIMARY'`, не называя таблицу.

`Dialect()` — это **не** `crud.Dialect.Name()`, который отвечает `"mysql"` и
для MariaDB тоже и потому не может их различить. Это единственное место в
дереве, где движок *измеряется*, а не декларируется.

## Один каталог на физический хендл

Каталог — это значение, которым владеет приложение, **никогда не переменная
уровня пакета** ([[D-041]]). Глобальная переменная верна в любом тесте с одной
базой данных и неверна в деплое, который имеет значение, — и в обоих случаях
молча.

```go
var cats catalog.Set   // нулевое значение уже готово к использованию

main,  err := cats.Load(ctx, mainDB)
events, err := cats.Load(ctx, analyticsDB)

if c, ok := cats.For(mainDB); ok { … }
```

`Set` использует ключи по правилу `crud.SameDataSource` — тому же правилу
идентичности, что использует `crud.WithExecutorFor`; второе воплощение этого
правила стало бы ровно тем расхождением, ради предотвращения которого это
существует. Записи хранятся в слайсе, а не в `map[any]`, потому что хендл
источника данных на практике является указателем, но контракт этого не
гарантирует, а несравнимый ключ карты паникует во время выполнения.

Хендл, который нельзя сравнить, отклоняется с `catalog.ErrUncomparableHandle`
вместо того, чтобы быть сохранённым там, где его никогда больше не найти.

## Что он хранит

| Тип | Содержит |
|---|---|
| `Table` | имя, схему, колонки в порядке движка, первичный ключ в порядке ключа, ограничения в детерминированном порядке |
| `Column` | имя, позицию с отсчётом от 1, собственный текст типа движка, nullable, значение по умолчанию, максимальную длину, generated |
| `Constraint` | имя, таблицу, вид, колонки в порядке ключа, выражения, префиксы, partial + предикат, `RefTable`/`RefColumns`, `OnDelete`/`OnUpdate`, deferrable |

Виды: `KindPrimaryKey`, `KindUnique`, `KindUniqueIndex`, `KindForeignKey`,
`KindCheck`.

`KindUnique` и `KindUniqueIndex` разделены, потому что два из четырёх движков
их различают, а два — нет: `Kind` фиксирует, какой это случай, вместо того
чтобы выдумывать ответ.

Три поля стоит знать перед тем, как на них полагаться:

- **`Column.MaxLength` в SQLite всегда 0.** `VARCHAR(255)` записан в `Type`, но
  ничего не enforce'ит; каталог, отвечающий 255, заявлял бы об ограничении,
  которого не существует ([[D-019]]).
- **`Column.Default` — указатель**, потому что MySQL сообщает `DEFAULT ''` как
  пустую строку, а обычная строка не может отличить «значения по умолчанию
  нет» от «значение по умолчанию — ничто».
- **`Constraint.Definition` — дословный текст движка, и его ничто не парсит.**
  CHECK хранится как исходный текст и никогда не вычисляется: восстановление
  выражения из этого текста — это парсинг DDL, а его [[D-041]] запрещает
  прямым текстом.

`Columns`, `Expressions` и `Prefixes` — **параллельны по позиции**: элемент *i*
каждого из них описывает часть ключа *i*. Probe читает свои результаты по
позиции колонки, а карта здесь потеряла бы порядок, который несёт эту
идентичность.

## Rolling-миграции

Имя ограничения, о котором каталог никогда не слышал, — это результат
rolling-миграции. Опциональный `Reloader` просит взглянуть ещё раз:

```go
if r, ok := cat.(catalog.Reloader); ok {
    _ = r.Reload(ctx, table, name)
}
```

То, что возвращает `Load`, реализует его; `Catalog` из другого места может не
реализовывать, так что проверяйте.

Он намеренно **не** входит в `Catalog`: поиск не делает I/O и не принимает
контекст — именно это делает `Load` тем, что может упасть, поэтому
единственный вызов, делающий I/O, не может сидеть на том же интерфейсе.

Негативный кэш с двумя защитами не даёт неизвестному имени переинтроспектировать
в цикле: интервалы начинаются с 1с и удваиваются до 5 минут, с полом в 1с между
проходами. Появившееся имя сбрасывает его.

## Обратное направление

```go
if r, ok := cat.(catalog.Referrers); ok {
    fks := r.ReferencedBy("orgs")   // какие внешние ключи ссылаются на эту таблицу
}
```

Ни один поиск в `Catalog` не может это выразить — ограничение записано на
таблице, которая его *объявляет*. Это то, что нужно `restrict`-пробе, а
каталог, не являющийся `Referrers`, просто не производит термов restrict.

## Чем он не является

Не ORM-схема, не инструмент миграций, не парсер DDL. Он читает то, что
сообщают четыре движка, и на этом останавливается. Каждое хранимое им поле —
это либо то, что нужно оператору [probe](probe.md), либо то, что нужно
[fault](sqlfault.md) для называния колонки, — и ничего не добавлено на том
основании, что читателю это может пригодиться.
