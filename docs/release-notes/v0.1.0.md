# v0.1.0 release notes

## OpenTelemetry extension candidate

This release candidate adds the optional `github.com/frostgrove/vv/otel`
module (`vvotel`) for service command spans, storage spans, terminal cache
observations and a generated, privacy-reviewed schema.

- The root module and non-OTel modules remain free of OpenTelemetry dependencies.
- Applications inject providers and own SDK exporters, readers/processors,
  flush and shutdown.
- Unknown cache values and non-standard error codes are omitted; IDs, keys,
  URLs, payloads, messages and credentials are not telemetry attributes.
- Provider and instrument panics are isolated from business results, errors and
  panic semantics.
- `ContractVersion` is `vv-otel/v1`; `ScopeVersion` follows the lockstep OTel
  module version.

Publication is gated until the root `v0.1.0` and `otel/v0.1.0` tags are available
to the Go module proxy and both strict consumer checks pass. Logs, jobs
propagation, repository spans and outbox/messaging remain deferred.
